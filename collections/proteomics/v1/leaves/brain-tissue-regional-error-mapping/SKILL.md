# brain-tissue-regional-error-mapping

## Summary

Compute regional normalized RMS error (NRMSE) of synthesized neuroimaging volumes separately within white matter, gray matter, and CSF masks derived from T1w FreeSurfer 5.3.0 parcellation, complementing whole-brain image-quality metrics for FA, PET, or MD synthesis from ADNI-3 multimodal MRI.

## When to use

Use when a synthesized 3D neuroimaging volume (e.g., FA, MD, or PET predicted from T1w and FLAIR) must be evaluated for tissue-specific accuracy beyond a single whole-brain error scalar.

## When NOT to use

- When only a single whole-brain quality score is needed and no tissue parcellation exists for the input T1w
- When evaluating synthesis of non-brain structures or images lacking a FreeSurfer-compatible anatomical reference
- When the target modality's quantitative values were rescaled to 0-1, since normalization negatively affects the quantitative value of DTI metrics

## Inputs

- Synthesized 3D volume from the test set (e.g., FA map generated by testing.py from T1w + FLAIR inputs)
- Ground-truth target volume for the same subject (e.g., DTI-derived FA fitted with the Quantitative Imaging Toolkit)
- Tissue parcellation masks (white matter, gray matter, CSF) from FreeSurfer 5.3.0 T1w preprocessing
- Subject list for the 99 held-out ADNI-3 test subjects

## Outputs

- Per-subject regional NRMSE values within WM, GM, and CSF masks
- Whole-brain NRMSE, peak SNR, and structural similarity per subject
- Group-level mean/SD metric table (e.g., fa_synthesis_nrmse_table.csv) for all compared networks

## How to apply

First run the synthesis network (e.g., SC-GAN trained in TensorFlow on 497 ADNI-3 subjects, 398 train / 99 test) over the held-out test set to produce synthesized volumes. Obtain tissue segmentation masks from the T1w preprocessing, which used FreeSurfer ver. 5.3.0 for parcellation. For each of the 99 test subjects, compute NRMSE between the synthesized volume and the ground-truth map over the whole brain and separately within the white matter, gray matter, and CSF masks, alongside peak SNR and structural similarity. Report results as mean/SD across subjects; in this study SC-GAN gave whole-brain NRMSE 0.078/0.012 with regional values of 0.088/0.012 (WM), 0.062/0.01 (GM), and 0.073/0.014 (CSF). Use the relative ranking against baselines (SC-GAN 18% lower error than 2D conditional GAN for FA) as the acceptance criterion.

## Related tools

- **SC-GAN** (Generates the synthesized FA/MD/PET volumes whose regional error is mapped; evaluated against 2D and 3D conditional GAN baselines) — https://github.com/Haoyulance/SC-GAN
- **FreeSurfer 5.3.0** (Provides the T1w parcellation masks used to restrict NRMSE computation to white matter, gray matter, and CSF)

## Examples

```
python testing.py --test_size=99 --gpu=0 --img_size=256 --data_dir=./data/test --modalities=flair_t1w_fa --logdir=./logs --output=./synthesized
```

## Evaluation signals

- Whole-brain NRMSE (mean/SD) for SC-GAN on the FA task should be approximately 0.078/0.012
- Regional NRMSE should fall near WM 0.088/0.012, GM 0.062/0.01, CSF 0.073/0.014, with GM error lower than WM error
- SC-GAN regional and whole-brain NRMSE should be lower than all baselines; prediction error should be ~18% lower than 2D conditional GAN for FA
- Evaluation must cover the full 99-subject held-out ADNI-3 test set, with the 2D network's 3D output evaluated directly for comparability

## Limitations

- Normalization of target DTI images to 0-1 for stable training negatively affects the quantitative value of the metrics, so regional error magnitudes are not directly interpretable in native intensity units
- Computational cost is a limitation of SC-GAN: lengthy training and heavy GPU memory requirements restrict rapid re-evaluation across models
- Metrics are computed only within FreeSurfer-derived tissue classes; errors outside parcellated tissue are not captured
