# psm-rescoring-with-predicted-spectral-features

## Summary

Data-driven rescoring of search engine PSMs using Prosit-predicted fragment intensities and iRT values generated via the Oktoberfest pipeline, with FDR estimation by mokapot. It uniquely recovers large numbers of additional peptides/PSMs (e.g. ~2574 peptides / 14,318 PSMs on HLA C*12:03 immunopeptidomics data).

## When to use

Use when you have unfiltered search engine results (e.g. MaxQuant/Andromeda) plus RAW spectra and want to boost identifications at 1% FDR by rescoring with predicted spectral features.

## When NOT to use

- Input is already a rescored feature table with FDR-estimated PSMs — rescoring again adds no Prosit-derived signal
- The job type is 'CollisionEnergCalibration' or 'SpectralLibraryGeneration' rather than 'Rescoring' (Oktoberfest distinguishes these three job types)
- Spectra are not searchable/search-engine-annotated PSMs (e.g. only raw spectral libraries without search results to rescore)

## Inputs

- Unfiltered MaxQuant/Andromeda search results (search result files convertible via pp.convert_search)
- Thermo RAW spectra files (converted to mzML with ThermoRawFileParser)
- Peptide sequence list / metadata for prediction (e.g. via pp.filter_peptides, pp.generate_metadata)

## Outputs

- Annotated PSMs with Prosit-derived rescoring features (fragment intensity and iRT)
- Rescored PSMs with target/decoy FDR estimation at PSM and peptide level from mokapot
- Uniquely identified peptide and PSM counts attributable to data-driven rescoring
- Summary and quality control figures/plots generated by the pipeline

## How to apply

Convert the search results to Oktoberfest internal format with pp.convert_search/pp.load_search, and convert Thermo RAW files to mzML via pp.convert_raw_to_mzml before loading spectra with pp.load_spectra. Retrieve Prosit fragment intensity and iRT predictions through the Koina interface (pr.Predictor/pr.Koina) and build rescoring features with re.generate_features, annotating experimental peaks with the default fragment mass tolerance of 20 (FTMS) / 40 (TOF) / 0.35 (ITMS) using 'da' or 'ppm' unitMassTolerance per mass analyzer and fragmentation_method 'HCD'. Optionally merge extra search-result columns as features via re.merge_input (add_feature_cols). Finally rescore the annotated PSMs with mokapot (re.rescore_with_mokapot) for target/decoy separation and FDR estimation on PSM and peptide level. Success is judged by whether the uniquely identified peptides and PSMs reproduce published gains (e.g. ~489% peptide and ~296% PSM improvements on the C*12:03 HLA dataset, with only 7 peptides and 49 PSMs lost).

## Related tools

- **Oktoberfest** (Open-source Python package that orchestrates the full rescoring pipeline: search conversion, feature generation, and FDR estimation) — https://github.com/wilhelm-lab/oktoberfest
- **Prosit** (Deep learning model providing in silico fragment intensity and iRT predictions used as rescoring features)
- **Koina** (Server interface through which Prosit predictions are retrieved (pr.Predictor/pr.Koina))
- **mokapot** (Performs target/decoy separation and FDR estimation on PSM and peptide level (re.rescore_with_mokapot))

## Examples

```
import oktoberfest as ok; ok.re.rescore_with_mokapot(input_file, fdr_estimation_method="mokapot")
```

## Evaluation signals

- Number of uniquely identified peptides after rescoring matches published value (~2574 on HLA C*12:03), corresponding to ~489% peptide gain
- Number of uniquely identified PSMs after rescoring matches published value (~14,318), corresponding to ~296% PSM gain
- Losses are minimal: only 7 peptides and 49 PSMs lost relative to the native search engine score
- mokapot FDR estimation produces valid target/decoy separation at PSM and peptide level
- Peak annotation uses the correct mass tolerance per mass analyzer: 20 (FTMS) / 40 (TOF) / 0.35 (ITMS) with appropriate 'da' or 'ppm' unitMassTolerance and fragmentation_method 'HCD'

## Limitations

- Gains are dataset-dependent; the cited figures (~489% peptide / ~296% PSM) come from a monoallelic HLA class I (C*12:03) immunopeptidomics dataset with non-tryptic peptides
- Peak annotation tolerance depends on the mass analyzer and must be set per instrument type (FTMS/TOF/ITMS); wrong units ('da' vs 'ppm') degrade feature quality
- Predictions require access to a Koina server (or equivalent) to retrieve Prosit fragment intensity and iRT values
- FDR estimation method must be chosen ('percolator' or 'mokapot'); the default is 'mokapot'
