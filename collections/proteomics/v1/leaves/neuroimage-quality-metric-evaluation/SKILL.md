# neuroimage-quality-metric-evaluation

## Summary

Evaluates the quality of synthesized 3D neuroimaging volumes (e.g., PET, FA, MD maps generated by GANs such as SC-GAN) against ground truth using three image-quality metrics: normalized RMSE (NRMSE), peak SNR, and structural similarity (SSIM).

## When to use

Use when a generated/synthesized 3D medical image volume (e.g., ADNI-3 PET or DTI-derived FA/MD maps) must be quantitatively compared voxel-wise against a ground-truth target to benchmark synthesis models.

## When NOT to use

- Synthesizing quantitative modalities whose absolute intensity values matter (e.g., quantitative DTI metrics) when the 0-1 normalization step would distort quantitative values — the paper notes normalization negatively affects quantitative metric values
- Evaluating tasks without paired ground-truth target volumes, since NRMSE, peak SNR, and SSIM all require voxel-wise comparison against a reference

## Inputs

- Synthesized 3D neuroimaging volumes (NIfTI, e.g., .nii.gz) from the testing script output directory
- Ground-truth target volumes (PET, FA, or MD maps) for the same test subjects
- Preprocessed input volumes at 256 x 256 x 256 with Z-score normalization and min-max rescaling to 0-1

## Outputs

- Per-subject NRMSE, peak SNR, and structural similarity values
- Comparison table CSV (e.g., md_synthesis_comparison.csv or ablation_results.csv) with the three metrics for all networks or ablation conditions

## How to apply

Run the trained synthesis network's testing script on the held-out test split (e.g., 99 ADNI-3 subjects for the MD task, 58 subjects for the PET task) to produce synthesized target volumes at 256 x 256 x 256. For each synthesized volume, compute normalized RMSE, peak SNR, and structural similarity against the ground-truth volume; for 2D networks, evaluate the 3D output directly in 3D for a fair comparison with 3D models. Assemble the metrics for all networks (or all ablation variants) into a comparison table (e.g., md_synthesis_comparison.csv or ablation_results.csv) and rank models by metric performance, expecting the strongest model to show the lowest NRMSE and highest PSNR/SSIM. When a component ablation is evaluated, attribute contribution by the magnitude of metric degradation when each component (self-attention, adversarial loss, B-rmse, spectral normalization, feature matching) is removed. Note that Z-score normalization followed by min-max rescaling to 0-1 was applied to volumes before training, so metrics are computed on the normalized intensity range.

## Examples

```
python testing.py --test_size=99 --gpu=0 --img_size=256 --data_dir=./data --modalities=flair_t1w_md --logdir=./logs --output=./synthesis_md
```

## Evaluation signals

- The comparison table contains NRMSE, peak SNR, and structural similarity for all evaluated networks (SC-GAN, 2D cGAN, 3D cGAN, Att cGAN) or all five ablation conditions plus full SC-GAN
- SC-GAN's MD-task NRMSE error is approximately 29% lower than 2D cGAN's, consistent with the reported result
- Ablation ranking shows removing adversarial learning and the self-attention module produces the largest metric degradation, followed by spectral normalization
- Synthesized volumes are evaluated at 256 x 256 x 256 on the same test subjects as the ground truth (e.g., 99 ADNI-3 subjects for MD, 58 for PET)
- Metrics are computed on intensities rescaled to the 0-1 range after Z-score normalization

## Limitations

- Computational cost is the main limitation of SC-GAN; it requires lengthy training and heavy GPU memory, constraining how many evaluation runs are practical
- Normalizing target DTI images to 0-1 for stable training negatively affects the quantitative value of DTI metrics, so quantitative-modality evaluations should avoid the normalization step
- The in-house test suggesting no normalization dependency in SC-GAN is not presented, so it cannot be verified from the published material
