# protein-embedding-feature-selection

## Summary

Ranks and selects an optimal feature subset from high-dimensional protein deep-representation-learning embeddings (e.g., the 5505D fused BiLSTM 3605D + UniRep 1900D vector) using feature-importance methods RF, LGBM, and MRMD3.0 before classifier training, as in prPred-DRLF for plant R protein prediction.

## When to use

Use when input is a high-dimensional protein embedding feature matrix (e.g., BiLSTM 3605D, UniRep 1900D, TAPE-BERT 768D, or fused 5505D) with binary labels, and an optimal low-dimensional feature subset must be selected before classifier training or ablation.

## When NOT to use

- Input is already a low-dimensional, curated feature table where selection adds no benefit and risks discarding informative dimensions
- The task requires raw sequence-level annotation (e.g., HMMER domain profiling) rather than embedding-based classification features
- Sequences have not been deduplicated (no CD-HIT filtering), so redundancy may inflate feature-importance and CV estimates

## Inputs

- Labeled protein FASTA sequences (e.g., 456-sequence Wang et al. plant R protein dataset: 152 positive, 304 negative, CD-HIT-filtered at 30% identity)
- Numerical embedding feature matrix from deep representation models: BiLSTM 3605D, UniRep 1900D, TAPE-BERT 768D, or fused BiLSTM+UniRep 5505D
- Binary class labels (R protein = 1, non-R protein = 0) with a train/test split (364 training / 92 independent test)

## Outputs

- Feature-importance rankings per selection method (RF, LGBM, MRMD3.0)
- Selected optimal feature subsets per method (reduced-dimension matrices)
- 5-fold cross-validation metrics table (precision, recall, ACC, F1-score, AUC) for each feature-selection × classifier combination, e.g., cv_benchmark_results.csv

## How to apply

Take the labeled embedding matrix (in prPred-DRLF, the 5505D fused BiLSTM+UniRep features for 364 training sequences, 152 positive/304 negative dataset reduced by CD-HIT 30% identity cutoff) and rank features by importance values generated by three selection methods: random forest (RF), LGBM, and MRMD3.0 (http://lab.malab.cn/soft/MRMD3.0/index.html). For each method, progressively select the top-ranked feature subsets and feed them to the classifiers (SVM, LGBM, RF, ET) under 5-fold cross-validation on the training set, computing precision, recall, ACC, F1-score, and AUC. Compare selection-method × classifier combinations to identify the best configuration; in the source study, LGBM feature selection paired with the LGBM classifier achieved the best CV performance (ACC 0.970, F1 0.953, AUC 0.988). Rationale: fusing two deep representation embeddings yields very high dimensionality relative to the small sample size, so importance-based selection removes noisy dimensions before model fitting.

## Limitations

- Deep representation learning feature methods require an elevated level of computing resources
- Parallel computing is not yet incorporated into the program; the authors plan it for future work to improve computational efficiency
