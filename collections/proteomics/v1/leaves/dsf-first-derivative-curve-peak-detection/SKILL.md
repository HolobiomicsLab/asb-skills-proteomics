# dsf-first-derivative-curve-peak-detection

## Summary

Automated data-screening routine from SimpleDSFviewer that runs peak finding on normalized, smoothed first derivative curves (FDCs) from DSF melting curves to classify each curve as single-Tm, two-Tm, no-Tm (>=4 peaks), or unfolded/denatured (declining MC), reporting results to tm_screening_results.csv.

## When to use

Use when classifying DSF melting curves via peaks in normalized, smoothed first derivative curves (FDCs): qualifying peaks must exceed 10% of the highest peak's width and height; flag no-Tm curves (>=4 peaks) and unfolded curves (declining MC).

## When NOT to use

- Input is raw, unnormalized/unsmoothed DSF fluorescence — peak finding here expects FDCs already produced by SimpleDSFviewer's MC normalization and smoothing step
- Goal is manual or visual Tm estimation from a single known peak where second-Tm discrimination, no-Tm flagging, and unfolded-curve classification are not needed
- Data are not thermal melting curves from differential scanning fluorimetry (e.g. isothermal fluorescence or non-protein thermal stability assays)

## Inputs

- Normalized and smoothed first derivative curves (FDCs) generated by SimpleDSFviewer from DSF raw fluorescence data
- Corresponding melting curves (MCs) used to assess whether the curve rises or declines
- Exemplar dataset: His-FGF10 DSF series including the 8 M urea sample

## Outputs

- Per-curve classification: single Tm, primary Tm plus second Tm, 'no Tm calculated' flag, or unfolded/denatured classification with initial temperature
- tm_screening_results.csv containing all per-curve outcomes

## How to apply

Load the normalized and smoothed first derivative curves (FDCs) produced by SimpleDSFviewer from the DSF dataset into Matlab (SimpleDSFviewer runs in the Matlab workspace or with Matlab Runtime). Run peak finding on each FDC and count only peaks whose width and height each exceed 10% of the highest peak in the assay as qualifying peaks; smaller peaks are treated as noise. For a single qualifying peak, report the corresponding Tm; for two qualifying peaks, report the primary Tm and the second Tm. If four or more peaks are recognized, flag the curve as 'no Tm calculated'. If the melting curve (MC) declines rather than rises, classify the sample as unfolded/denatured and return the initial temperature (e.g. 32 C for His-FGF10 in 8 M urea). Write all per-curve outcomes — Tm values, second Tm, no-Tm flags, unfolded/denatured classifications with initial temperature — to tm_screening_results.csv.

## Evaluation signals

- The exemplar His-FGF10 curve in 8 M urea is classified as unfolded/denatured and returns the initial temperature of 32 C
- Curves with >=4 recognized peaks carry a 'no Tm calculated' flag in tm_screening_results.csv
- Peaks whose width or height is <=10% of the highest peak in the assay are excluded as noise and do not count as qualifying peaks
- A curve with exactly one qualifying peak yields one Tm; a curve with two qualifying peaks yields a primary Tm and a second Tm
- All per-curve outcomes (Tm values, second Tm, no-Tm flags, unfolded classifications with initial temperature) are present in tm_screening_results.csv

## Limitations

- Peaks below the 10% width/height threshold of the highest peak are treated as noise, so small genuine transitions may be missed
- Curves with four or more recognized peaks yield no Tm value at all (flagged 'no Tm calculated')
- Unfolded/denatured curves (declining MC) only return the initial temperature, not a true Tm
