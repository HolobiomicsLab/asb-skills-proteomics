# feature-subset-selection

## Summary

Extracts an optimal feature subset from high-dimensional deep representation learning embeddings (fused BiLSTM 3605D + UniRep 1900D = 5505D) for plant R protein identification by comparing RF, LGBM, and MRMD3.0 feature-selection techniques and ranking features by importance before classification with an LGBM classifier.

## When to use

Use when input is protein sequences embedded into high-dimensional vectors (e.g., 3605D BiLSTM, 1900D UniRep, 768D TAPE-BERT, or 5505D fusions) and a compact discriminative subset must be selected before training a classifier.

## When NOT to use

- Input is already a compact curated feature table where dimensionality reduction would discard informative attributes
- Sequences have not yet been embedded — redundancy must first be removed with CD-HIT (30% identity cutoff) and vectors generated via eFeature
- The goal is predicting novel sequences with the deployed prPred-DRLF predictor rather than comparing feature-selection techniques during model development

## Inputs

- Protein sequences in FASTA format from the Wang et al. plant R protein dataset (456 sequences: 152 positive, 304 negative; 364 train / 92 independent test)
- Numerical embedding vectors: BiLSTM 3605D, UniRep 1900D, TAPE-BERT 768D, and fusions such as BiLSTM+UniRep 5505D
- Binary labels (1 = R protein, 0 = non-R protein)

## Outputs

- Feature importance rankings generated by RF, LGBM, and MRMD3.0
- Optimal selected feature subset from the fused BiLSTM+UniRep feature vector
- Per-combination evaluation metrics (accuracy, precision, recall, F1-score, AUC) saved as feature_combination_metrics.csv

## How to apply

Embed sequences into numerical vectors using eFeature with BiLSTM, UniRep, and TAPE-BERT models, then construct feature combinations including the fused BiLSTM+UniRep vector (5505D). Rank features by importance values generated with three techniques — random forest (RF), LGBM, and MRMD3.0 — and compare them to extract the optimal feature subset from the fused vector. Validate each candidate subset with fivefold cross-validation on the 364 training samples, then feed the selected subset to the LGBM classifier. Evaluate the selected subset on the 92-sample independent test set with precision, recall, accuracy, F1-score, and AUC; in prPred-DRLF the LGBM-selected fused BiLSTM+UniRep subset achieved accuracy 0.956, precision 0.967, recall 0.905, F1 0.933, and AUC 0.997.

## Related tools

- **LightGBM (LGBM)** (Used both as a feature-selection method ranking features by importance and as the downstream classifier applied to the selected subset) — https://github.com/Wangys-prog/prPred-DRLF

## Examples

```
python3 prPred-DRLF.py -i ./dataset/test_data.fasta -o ./dataset/predict_result
```

## Evaluation signals

- All three selection techniques (RF, LGBM, MRMD3.0) produce ranked feature subsets from the 5505D fused vector
- Fivefold cross-validation on the 364 training samples shows the selected subset retains effectiveness before independent testing
- Independent-test metrics for the LGBM-selected fused BiLSTM+UniRep subset match accuracy 0.956, F1-score 0.933, AUC 0.997 (precision 0.967, recall 0.905)
- Selected subset dimensionality is substantially smaller than the original 5505D fused vector while AUC remains ≥ 0.997 on the 92-sample test set
- Comparison rows across all feature combinations are complete in feature_combination_metrics.csv

## Limitations

- Deep representation learning features require an elevated level of computing resources
- Parallel computing is not yet incorporated into the program; the authors plan it to achieve high computational efficiency
- Python version pinning matters: the toolkit depends on Python 3.7 with specific packages (e.g., lightgbm-2.3.0, tape_proteins==0.5, pandas==1.2.0)
